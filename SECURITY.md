# Security Policy

## Supported version

Security fixes are made against the latest commit on `main`.

## Reporting a vulnerability

Please do **not** open a public issue for a suspected vulnerability or an exposed credential.

Use the repository's [private vulnerability reporting form](https://github.com/EnzeD/speed-widget/security/advisories) and select **Report a vulnerability**. Include a clear description, reproduction steps, affected version or commit, and the potential impact. Do not include live credentials in a report; revoke or rotate them first if possible.

Reports are reviewed in good faith. Once a report is confirmed, the maintainers will work on a fix and coordinate disclosure through a GitHub security advisory when appropriate.

## Scope

The source code, GitHub Actions workflow, packaging script, and distributed macOS app bundle are in scope. General network outages, third-party endpoint availability, and score accuracy are product issues rather than security vulnerabilities; please use a normal issue for those.
